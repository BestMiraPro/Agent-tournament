## Task 1 — Round-detail endpoint

**Files:** `src/server/api.ts` (one route), `test/server/round-detail.test.ts` (new;
or extend analytics-api.test.ts if its seed fits — your call, say which).

Per spec §3 (shape verbatim): `GET /api/runs/:runId/rounds/:idx` → header fields
(`idx, goalMd, criteriaMd, criteriaSource, metaDigest, costUsd, status,
judgeMode`) + `entries` ASC by rank (agent join: label; round-idx genome:
modelId; score row; submission-or-null — mirror the agent-detail `history`
assembler; a shared private helper is fine if it reads better).
Rules: 404 run/round-idx; unscored round → 200 with `entries: []` (do NOT 404);
`judgeMode` from the row, NO judge model (spec honesty rule — comment it).
Tests (write first): seeded 2-round run — full header on a user-criteria round +
generated round, rank-ordered entries with submission join + one null-submission,
rationale text present; 404 run; 404 bad idx; created-but-unscored round → 200,
header fields, `entries: []`.

Gate. Commit: `feat: round-detail endpoint with entries rank-ordered`.

## Task 2 — Round detail panel + run summary strip

**Files:** `web/src/api.ts` (`getRoundDetail`), `web/src/components/RoundDetail.tsx`
(new), `web/src/components/RunSummary.tsx` (new), `web/src/App.tsx` (mount both),
`web/src/styles.css`.

1. `getRoundDetail(runId, idx)` — file convention, type mirrors §3 exactly.
2. `RoundDetail({ runId, rounds, busy })` — `rounds` = round-stats entries (have
   idx; select over COMPLETED rounds default-latest + the in-flight idx when
   busy); fetch on select; header (goal, criteria + source badge, metaDigest via
   `<Markdown>`, cost `$X.XXXX`, status); entries rank-ordered cards (rank badge,
   label + model badge, score `toFixed(2)`, band; rationale `<Markdown>`;
   submission in `<details>` with `<Markdown>` body + manifest list + tokens/cost
   line + error block when non-ok). Loading/error/empty one-liners (file
   conventions). Mounted below AnalyticsPanel.
3. `RunSummary({ snapshot, busy, roundStats })` — top of arena: name + sandbox
   badge + status; rounds completed; best score + round idx (max of maxes — NO
   agent name, data doesn't carry it); total cost (sum, `$X.XXXX`); "N active /
   M rostered" (actives = snapshot.agents.length, rostered = roster counts sum).
   Pure presentational (no fetch inside — props only).
4. `App.tsx`: mount both with existing state (no new polling — round-stats fetch
   already exists from 4c; reuse its data for the selector + summary).
5. No server code. No other component behavior change.

Gate (no new web harness; bar is typecheck + build + Task 5 e2e). Commit:
`feat: round detail panel and run summary strip`.
